# AT 과제 관리 시스템

2026-11-23 기준 최신 구현본입니다. 추가 JavaScript 패키지 설치 없이 실행하는 정적 웹 앱입니다.

## 실행 방법

1. GitHub에서 저장소를 복제하거나 ZIP을 내려받아 압축을 풀고, 터미널에서 프로젝트 폴더로 이동합니다.
2. Python 3가 설치된 환경에서 아래 명령을 실행합니다.

```sh
python3 -m http.server 8000 --directory dist
```

Windows에서 `python3` 명령이 없다면 `py -3 -m http.server 8000 --directory dist`를 사용합니다.

3. 브라우저에서 <http://localhost:8000>을 엽니다. 서버 종료는 터미널에서 Ctrl+C입니다.

`index.html`을 직접 여는 대신 localhost로 실행해 주세요. 메신저용 입력 링크는 HTTP/HTTPS 주소를 사용합니다. 별도 웹 서버에 배포할 때는 `dist` 폴더 전체를 올리고 HTTPS로 운영합니다.

## 포함 기능

- 팀·PO·PM·공동 수행자, Tech·과제 분류를 포함한 등록·검색·조회
- 시작일·종료일 및 연도별 12개월 누적 목표 입력표
- 별도 월별 누적 실적, 지연 사유·Catch Up Plan, 누적 지연 판정
- 운영 인박스, 관리 대시보드, 과제별 규칙 기반 Summary
- 정보·담당자·일정·목표 변경 승인·반려·철회와 최초 계획 비교
- 승인 시 최신 실적 보존, 전체 활동 이력·내보내기, 보관·복구 승인
- 실적 요청 대상·기한·메시지 미리보기, 중복 방지와 요청 이력
- 메신저 연동 요청 파일 준비 및 대상 월 실적 입력 링크

## 데이터와 연동 상태

현재는 브라우저 저장 기반 시연입니다. 브라우저·주소·포트가 바뀌면 과제 저장 공간도 달라집니다.

이 ZIP에는 앱에 기본 포함된 가상 예시 3건이 들어 있습니다. 기존 배포 사이트의 현재 브라우저에 등록한 과제·승인·실적·요청 데이터는 포함되어 있지 않습니다.

SSO 로그인, 조직도, 서버 권한 검증, 공용 데이터베이스, 사내 AI, 메신저 실제 발송은 연결 전입니다. 이름·역할을 입력하는 승인 기능은 검토 흐름의 시연이며 실제 계정 권한을 부여하지 않습니다. AI Summary는 규칙 기반 분석입니다. 메신저 요청 준비와 파일 생성은 발송 완료로 처리하지 않습니다.

서버 연동 규격은 `docs/messenger-integration.md`를 참고해 주세요.

## 구성

- `dist/`: 실행용 HTML·JavaScript·CSS. 수정 가능한 앱 소스입니다.
- `tests/`: 계산·승인·요청·저장 흐름을 검증하는 테스트 7개 파일
- `docs/messenger-integration.md`: 사내 메신저 연동 규격 초안
- `VERSION.txt`: 소스 버전 정보

## 검증

Node.js 22 환경에서 프로젝트 폴더에서 실행합니다. 추가 패키지는 필요 없습니다. GitHub에서도 push와 PR마다 같은 검증을 실행합니다.

```sh
node --test
```

제공 시점에 자동 검증 78건을 통과했습니다. 승인 전 원본 유지, 승인 대기 중 실적 보존, 자기 승인 제한, 보관·복구 및 요청 중복 방지도 실제 화면에서 점검했습니다.
